很多老板认为"WiFi 密码设得复杂就安全了"。这个理解里有个前提错了：**WiFi 密码保护的是接入，不是访问。**

连上网络之后能做什么，和密码强度完全无关。

## 密码能防的和不能防的

| 威胁 | 密码能防吗 |
|---|---|
| 陌生人用你的带宽 | 能 |
| 邻居蹭网 | 能（但换了密码他们会再来问） |
| 局域网里的设备被扫描 | **不能** |
| 收银机被入侵 | **不能** |
| 顾客手机中毒后横向传播 | **不能** |
| 你的宽带 IP 被用来做违法的事 | **不能** |

后面这几条，只要对方进了同一个局域网，密码就再没有任何作用了。因为**密码是进门用的，进门之后在屋里能走到哪，是另一套机制决定的**。

## 真实的风险长什么样

举一个具体的场景。

你的店里有：一台收银机（Windows 系统）、一台监控录像机、一个扫码枪接收器、若干顾客手机。全部连在同一个 WiFi 下。

现在有一位顾客的手机中了恶意软件，这是一个自动运行的、机主完全不知情的程序。它做的事：

1. 扫描所在网段所有 IP（`192.168.1.1` 到 `192.168.1.254`）
2. 对每个有响应的 IP 尝试常见端口（3389 远程桌面、445 文件共享、80 管理页面）
3. 尝试常见弱口令（admin/admin、admin/123456、空密码）

你的收银机很可能用着出厂默认密码，或者 Windows 的远程桌面开着。整个过程在顾客喝咖啡的十分钟里完成，机主毫不知情。

**这个场景里，WiFi 密码是 `A8x!k2Lm` 还是 `88888888` 没有任何区别。**

## 真正起作用的三件事

### 一、网络隔离（最有效）

把顾客设备和你自己的设备放在不同网络里，让第 1 步的扫描根本扫不到你的收银机。

做法就是开访客网络，前提是它做了真正的网段隔离。判断方法写在[《访客网络该不该开》](/posts/guest-network.html)。

### 二、关键设备走有线

收银机、监控录像机、点单屏这些位置固定的设备，**能拉网线就拉网线**。

有线设备不参与无线的邻居发现过程，从顾客手机的角度看，它基本"不存在"。这一步不需要路由器支持任何高级功能，成本就是一根网线。

### 三、改掉默认管理密码

这是最便宜也最常被忽略的一步。设备出厂密码几乎都是几个固定组合，攻击者手里有完整的默认密码表。

需要改的默认密码至少有这些：

- 路由器后台管理密码
- 收银机的 Windows 登录密码 + 关闭远程桌面
- 监控录像机的管理密码
- 打印机、扫码枪接收器等网络设备的密码

**注意：WiFi 密码和路由器后台管理密码是两件事，很多人只改了前者。** 路由器后台的默认密码通常是 `admin/admin`，而且默认允许从局域网访问。这意味着任何连上你 WiFi 的人都能改你的路由器设置。

## 密码该设成什么

既然密码的作用只是"管理谁能接入"，那么设置标准就简单了：

- **长度 12 位以上**，包含大小写字母和数字
- **不要用手机号、店名、门牌号**
- **不要用 `12345678` `88888888` `66668888` 这类**——它们在有字典的破解工具面前等于没有
- **门店场景下可以用一句自己的口令转写**，比如"店开张那天是三月八日"→ `DianKaiZhang0308`。好记又不容易猜

但请记住：**这是最不重要的一步。** 花时间设复杂密码，不如花十分钟把收银机的默认密码改掉、把远程桌面关掉。

## 一份五件事的清单

按重要性排序，做完前两件你的风险就降低了大部分：

| 顺序 | 做什么 | 成本 |
|---|---|---|
| 1 | 关键设备拉网线 | 一根网线 |
| 2 | 改掉所有设备的默认管理密码 | 半小时 |
| 3 | 开访客网络做隔离（确认真的隔离） | 十分钟 |
| 4 | 关掉收银机的远程桌面和文件共享 | 五分钟 |
| 5 | 把 WiFi 密码设复杂 | 五分钟 |

大部分人只做了第 5 件，然后觉得安全了。
