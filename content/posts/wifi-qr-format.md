有一件事很多人没意识到：**WiFi 二维码里没有图像识别，也没有云端查询，它就是一段纯文本。** 手机相机扫到之后，读到的是一串固定格式的字符，系统解析这串字符后直接发起连接。

这段文本长这样：

```
WIFI:T:WPA;S:ChinaNet-3v9I-5G;P:88888888;;
```

逐段拆解：

| 片段 | 含义 |
|---|---|
| `WIFI:` | 开头标记，告诉系统"这是一条 WiFi 配置" |
| `T:WPA;` | 加密类型：WPA / WEP / nopass |
| `S:` | SSID，即网络名称，到下一个未转义的 `;` 为止 |
| `P:` | 密码 |
| `H:true;` | 可选，表示这是隐藏网络 |
| 结尾的 `;;` | 一个结束字段，一个结束整条记录 |

字段顺序不固定，手机不依赖顺序，而是认 `S:` `P:` 这些字母前缀。

## 为什么有些密码会让二维码失效

关键在**分号**。上面每个字段都用 `;` 分隔，如果密码里本身含有分号，系统就会把它当成字段结束符，解析出错。

标准的解决办法是**反斜杠转义**。需要转义的字符有五个：

```
\  ;  ,  :  "
```

举例：密码是 `ab;cd`，二维码里必须写成 `P:ab\;cd;`。

店铺 WiFi 密码里出现这些字符的概率不高，但如果你设过类似 `wifi:2026` 这种带冒号的密码，就会踩到这个坑。**建议门店密码只用数字和字母**，省掉一整类麻烦。

## 哪些系统支持

| 系统 | 支持情况 |
|---|---|
| iOS 11 及以上 | 自带相机直接识别，弹出"加入网络" |
| Android 10 及以上 | 自带相机或 Google Lens 识别，部分机型需装扫码工具 |
| 微信 | 扫一扫支持识别，长按图片识别也支持 |
| macOS / Windows | 相机不支持，需要专门的扫码软件 |

**iOS 11 之前和 Android 10 之前的老设备不支持**，扫出来只会看到一串看不懂的文本。这是给顾客用时要考虑的现实问题——如果常有老年顾客，贴个文字密码仍然必要。

## 对门店的实际意义

这个格式带来一个很实用的结论：**你可以同时提供两条路，成本几乎为零。**

在墙上贴一张纸，上面既印二维码，也印上手写的文字密码。扫码的人快，扫不动的人照着手输。这是容错率最高的做法。

另外一个提醒：**不要把 WiFi 二维码印成彩色的、带艺术设计的、中间压大 LOGO 的。** 二维码的纠错机制能容忍一定程度的遮挡和污损，但中心区域压上大块图形会明显降低低端手机的识别率。黑白方块、留足白边，是最可靠的样子。

在手机上展示二维码让别人扫的时候，还要注意屏幕反光和亮度。**屏幕调到最亮，手机不要贴太近**（太近相机会对不上焦），距离 15～25 厘米最稳。

## 为什么它不能替代"网页里点一下就连接"

因为它是**给相机用的，不是给网页用的**。

浏览器没有任何办法调用系统 WiFi 接口——这是操作系统的安全边界，不是浏览器功能没做完。所以一个网页能做到的最接近的方案，就是把这个二维码画在页面上，让用户截图后用相机或相册识别。这中间必然多一步。
