掉线比"上不了网"更难查，因为它发生时你不在现场。但有一个问题能立刻缩小排查范围：

> **同一时刻，是店里所有设备都掉，还是只有某一台掉？**

## 情况一：所有设备同时掉

问题在网络侧，不在设备侧。三个常见原因：

### 1. 运营商线路不稳定

特征是**掉线时间有规律**或**和天气/时段相关**。比如每天固定时段掉，或者下雨天掉得多。

**判断方法**：登录路由器后台，找"系统日志"或"连接状态"，看 PPPoE 断线记录。有记录就是线路问题。

**处理**：打运营商客服报修。**注意表述方式**——说"频繁掉线"客服可能让你重启，说"路由器日志里有 PPPoE 反复断线记录，怀疑线路问题"，处理效率完全不同。把日志截图保存好。

### 2. 光猫过热

光猫是 24 小时通电的设备，夏天放在密闭弱电箱里很容易过热。过热后它会重启或降频，表现就是整片断网。

**判断方法**：摸一下光猫外壳，明显烫手（超过 50℃ 的感觉）就是过热。看光猫的"电源"灯，如果掉线时这个灯闪烁，说明设备重启了。

**处理**：把光猫从密闭箱子里拿出来，或者加一个小风扇。这是个土办法，但确实有效。

### 3. 路由器重启

和光猫同理。**看路由器的运行时长**——多数后台首页有"已运行时间"。如果掉线后这个数字归零，说明路由器重启了。

路由器重启的常见原因是固件 bug 或电源适配器老化。换个电源适配器试试，成本很低。

## 情况二：只有一台设备掉

问题在那台设备上，常见原因：

### 1. 省电策略导致的"假掉线"

手机、笔记本在息屏或休眠后会降低 WiFi 功率甚至断开连接。唤醒时需要重新关联，如果这时信号不好，就会关联失败。

表现：**屏保或锁屏一段时间后，解锁发现 WiFi 断了。**

这是系统的正常行为，不是故障。如果影响使用（比如后厨的点单屏待机后连不上），在设备的电池设置里关掉"WiFi 休眠"选项。

### 2. 信号处于临界值

设备放在信号强度 -75 dBm 左右的边缘位置，稍微有人走动、门开关一下，信号就掉到阈值以下，导致断连。

**判断方法**：看掉线时那台设备的位置有没有变化，或者是不是在特定角落才掉。

**处理**：挪动路由器位置，或者给那个区域加一个 AP。让信号强度稳定在 -65 dBm 以上。

### 3. IP 地址冲突

手动设过静态 IP 的设备，如果这个 IP 后来被 DHCP 分配给了别人，就会冲突。表现是随机断连。

**处理**：把那台设备的 IP 设置改回"自动获取"。

### 4. 设备自身的 WiFi 模块问题

老旧设备、便宜的智能家居设备（尤其是几十块钱的智能插座）WiFi 模块质量差，兼容性问题多。

**判断方法**：把那台设备拿到路由器旁边试。如果近距离也掉，就是设备本身的问题。

## 一个容易被忽略的原因：2.4GHz 干扰

如果掉线集中在某几个时段，且店里或附近有这些设备，要考虑同频干扰：

- 微波炉（工作时直接压制 2.4GHz）
- 无线摄像头、无线图传
- 隔壁店新装了路由器
- 蓝牙设备密集（蓝牙也用 2.4GHz）

**判断方法**：用 WiFi 分析仪 App 看 2.4GHz 的拥挤程度。如果能看到十几个邻居网络叠在一起，说明这个频段已经不可用了。

**处理**：把能改的设备全部改到 5GHz。改不了的（智能插座、扫码枪）留着，但别指望它们在 2.4GHz 上稳定。

## 快速定位表

| 现象 | 最可能的原因 |
|---|---|
| 全店同时掉，每天固定时段 | 运营商线路 |
| 全店同时掉，夏天下午居多 | 光猫 / 路由器过热 |
| 全店同时掉，后台运行时间归零 | 路由器重启（查固件或电源） |
| 锁屏后掉，解锁需手动重连 | 设备省电策略，正常现象 |
| 某个角落固定掉 | 信号处于临界值，加 AP |
| 某台设备随机掉 | IP 冲突，改回自动获取 |
| 微波炉工作时掉 | 2.4GHz 同频干扰，改 5GHz |

## 建议做的两件事

**一、给路由器后台开日志，并定期看一眼。** 多数路由器支持把日志发到指定邮箱或保存到 U 盘。有了日志，掉线就不再是"玄学问题"。

**二、记录掉线时间。** 让店员在掉线时用手机记一下时间点。连续记一周，规律就出来了。**有规律的故障比随机故障好查得多**，也更容易跟运营商说清楚。
