"信号满格但打不开网页"是我们上门遇到最多的故障。它的成因比"没信号"要复杂——信号满格说明手机和路由器之间的连接是好的，**问题出在路由器往外走的那一段**。

按下面的顺序排查，每一步都能排除一类原因，不用跳着试。

## 第 0 步：先分清楚是哪一段断了

打开手机浏览器访问一个你从没访问过的网站（避免缓存），同时看路由器上的指示灯：

| 现象 | 指向 |
|---|---|
| 所有网站都打不开，路由器"Internet/光信号"灯**红或灭** | 上行链路问题（第 1、2 步） |
| 打不开网页，但微信还能收到消息 | DNS 问题（第 3 步） |
| 大部分网站能开，个别打不开 | 特定网站或 IP 问题，不是你的网络故障 |
| 只有一台设备不行，其他正常 | 那台设备的问题，与网络无关（第 5 步） |

## 第 1 步：宽带欠费

**这一步被跳过的次数多到离谱。** 很多老板第一反应是重启路由器，折腾半小时，最后发现是宽带到期忘了续费。

查法：登录宽带运营商的 App（中国电信、中国移动、中国联通都有），看账户状态和余额。或者直接打客服电话。

**先查这个，30 秒的事。**

## 第 2 步：看光猫的指示灯

光猫上通常有一个标着"光信号"或"LOS"的灯：

| 灯的状态 | 含义 | 怎么办 |
|---|---|---|
| 常亮绿灯 | 光纤正常 | 继续第 3 步 |
| **红灯闪烁或常亮** | 光信号丢失 | 光纤断了或接口松了，打运营商报修 |
| 完全不亮 | 设备没通电 | 检查电源适配器 |

红灯的情况自己修不了——光纤断了要么是外力挖断，要么是接头脏了，都需要运营商上门。**直接报修，别自己拆。**

另外看一下光猫的网线有没有松。光纤接口和网线接口都插紧一次，有时候就是接触不良。

## 第 3 步：DNS 问题

**判断特征：微信能发消息（它用 IP 直连），但浏览器打不开任何网页。** 这是 DNS 解析失败的典型表现。

DNS 的工作是把 `www.example.com` 翻译成 IP 地址。如果路由器下发的 DNS 服务器挂了，所有需要域名解析的操作都会卡住。

**修法**：进路由器后台，把 DNS 从"自动获取"改成手动指定：

```
首选：223.5.5.5    （阿里公共 DNS）
备用：119.29.29.29 （腾讯公共 DNS）
```

这两个是国内可用的稳定公共 DNS。改完保存，一般立刻恢复。

## 第 4 步：路由器本身的问题

前面的都正常，就重启路由器。但**重启要有正确的方式**：

**错误的做法**：拔电源，等 3 秒，插回去。

**正确的做法**：拔掉电源，**等 30 秒以上**，再插回去。

为什么是 30 秒：路由器内部的电容需要时间放电，里面的内存和状态表要彻底清空才叫真重启。等 3 秒就插回去，很多状态其实还留着，重启不彻底。

这解释了那个常见现象：**"我重启过了没用"**，其实是没重启干净。

如果是经常需要重启才正常，说明路由器的内存或处理能力已经不够（设备太多或固件有问题）。这时候换设备比反复重启更实际。

## 第 5 步：只有一台设备不行

如果其他设备都正常，问题在那台设备上，检查：

1. **飞行模式开关一次**，强制重新注册网络
2. **忘记这个 WiFi 再重新连**（清掉可能已损坏的配置）
3. **IP 地址冲突**：进 WiFi 详情看 IP，如果是 `169.254.x.x` 开头，说明**没拿到 DHCP 分配的地址**——通常是路由器地址池满了，或者这台设备被分配了静态 IP 且和别人的冲突
4. **时间和日期不对**：系统时间错乱会导致 HTTPS 证书校验失败，表现就是"所有网页都打不开"。这一条很隐蔽，但确实常见

第 4 条特别值得说：手机时间如果偏差超过一天，几乎所有的 HTTPS 连接都会失败，浏览器会给出证书错误。用户往往会忽略这个提示以为是网络问题。

## 第 6 步：地址池耗尽

如果店里的设备很多（超过 30 台），可能出现**新设备连不上、老设备正常**的情况。

原因是路由器的 DHCP 地址池通常默认只有 50 到 100 个地址，而且在设备离开后，地址要等租期到期才会回收（租期常设 24 小时）。一天下来大量顾客来来去去，地址可能被占满。

**修法**：进路由器后台，把 DHCP 租期从 24 小时缩短到 **2 小时**，或者扩大地址池范围（比如从 `192.168.1.100-199` 改成 `192.168.1.100-250`）。

对门店场景，**把租期设短是正确的**——顾客不会待 24 小时，没必要占着地址不放。

## 排查顺序速查

```
1. 宽带欠费了吗          ← 先查这个，30 秒
2. 光猫 LOS 灯红了吗     ← 红了就报修
3. 微信能发但网页打不开  ← 改 DNS
4. 重启（拔电等 30 秒）
5. 只有一台设备不行      ← 是那台设备的问题
6. 设备多、新设备连不上  ← 缩短 DHCP 租期
```

按这个顺序走，绝大多数情况在第 1、3、4 步就解决了。
