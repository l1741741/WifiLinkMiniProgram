公共 WiFi 的真实风险，以及被夸大的部分

上网安全 2026-09-01 约 3 分钟

关于"公共 WiFi 危险"的说法很多，但其中相当一部分是十年前的经验，在今天的网络上已经不成立。分清楚这两类，才不至于把精力花在错的地方。

已经被 HTTPS 消灭的风险：流量窃听

这是流传最广的一条：连上公共 WiFi，同一网络里的人就能抓走你的账号密码。

在今天基本不成立了。 原因是 HTTPS 已经普及。现在主流网站、App、小程序全部走加密连接，同一局域网里的人即便抓到了数据包，看到的也是加密内容。Let's Encrypt 免费证书把 HTTPS 的使用率推到了 90% 以上，明文传输的网站已经很少。

例外：极少数老旧系统或内部系统仍然使用 HTTP。如果你连上公共 WiFi 后，浏览器地址栏没有那个锁形图标，且警告"不安全"，那这次通信确实可以被看到。

判断方法很简单：看地址栏有没有锁。 有锁就基本安全，没锁就别在这上面输密码。

今天仍然成立的风险

一、伪造的热点（钓鱼 WiFi）

有人架一个叫"星巴克免费WiFi"的热点，你连上去之后，打开的其实是他控制的网络。他可以：

  • 把你引导到伪造的登录页，骗你输入手机号和验证码
  • 篡改 DNS，把你导到假的银行网站

这类攻击不需要破解加密，它骗的是你。

防御方法：连公共 WiFi 前跟店员确认名称。不要连名称可疑或有多份"官方"版本的热点。看到要求输入手机号、身份证、银行卡才能上网的页面，直接关掉。

二、局域网横向攻击

同一个网络里，设备之间默认可以互相访问。攻击者可以扫描网段，寻找开放了远程桌面、文件共享、或者弱口令的设备。

这个风险对手机用户较低（手机一般不开放端口），对带笔记本办公的人较高——尤其是开启了文件共享的 Windows 电脑。

防御方法：带笔记本连公共 WiFi 时，在系统设置里把网络类型标为"公用网络"，Windows 会因此关闭文件和打印机共享。这个设置很重要，而且很多人从来没改过。

三、设备指纹与行为记录

网络运营商和 WiFi 提供方能看到：你访问了哪些域名、连接了什么时间、用了多久。在 HTTPS 普及的今天，他们看不到具体的页面内容，但域名（SNI）通常是可见的。

这一条不是攻击，是客观存在的信息暴露。你在意的话，可以用 VPN 或加密 DNS。

被高估的部分

"连了公共 WiFi 手机就会被入侵" —— 不成立。手机系统本身的沙箱隔离做得比较好，仅靠连上同一个网络，攻击者没有直接入侵手机的手段。需要配合钓鱼、诱导安装应用等手段。

"公共 WiFi 会偷走你手机里的照片" —— 不成立。同上，需要你先授权或安装恶意应用。

"用公共 WiFi 会被人看到银行密码" —— 前提是你在 HTTP 页面上输，或者被引导到钓鱼页面。正常使用银行 App（走 HTTPS + 证书校验）是安全的。

一份实际可用的清单

连公共 WiFi 时，按这个顺序做：

  1. 跟店员确认 WiFi 名称，别连错
  2. 地址栏没锁的时候不输任何密码
  3. 笔记本把网络设为"公用"，关掉文件共享
  4. 涉及转账、支付时，切换到移动数据。这是最省事的兜底做法——一条 4G/5G 连接比任何安全设置都可靠
  5. 不用时关掉 WiFi 自动连接，避免手机自动连上不认识的网络

第 4 条是真正有效的建议。与其研究公共 WiFi 的各种风险，不如在需要处理敏感操作时直接切到流量。成本几乎为零，效果立竿见影。

对店家的意义

如果你经营门店并提供顾客 WiFi，上面这些同样适用于你：

  • 把顾客网络和收银设备隔离（见《访客网络该不该开》），你的收银机就不会成为顾客设备扫描的目标
  • 在 WiFi 登录页上不要收集手机号，那是不必要的责任
  • 不要记录顾客的上网日志，除非你有明确的合规理由和告知机制

具体来说，顾客连你家 WiFi 时你能看到什么、看不到什么，写在《顾客连你家 WiFi，你能看到什么》。
