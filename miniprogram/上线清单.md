# 上线清单

从"能用"到"上线"，按顺序走。**顺序不能乱**——后一步的前提都是前一步。

```
现在：个人主体 AppID（开发调试已跑通）
  │
  ├─ ① 主体变更：个人 → 企业          ← 必须，否则不能认证
  ├─ ② 微信认证                         ← 必须，否则不能备案
  ├─ ③ 备案                             ← 必须，否则不能发布
  ├─ ④ 配置隐私保护指引                 ← 必须，否则接口被禁用
  ├─ ⑤ 提交审核 → 发布
  └─ ⑥ 开通流量主 + 生成门店小程序码     ← 变现
```

**标注说明**：🖐 只能你在微信后台做 ｜ 🤖 我可以帮你做

## 一、账号（🖐 全部只能你做）

### ① 主体变更：个人 → 企业

因为现在这个 AppID 是个人主体，而 **WiFi 接口、微信认证、备案都要求非个人主体**。
好消息是 **AppID 不变**，所以已经跑通的东西不用重做。

| 项 | 说明 |
|---|---|
| 路径 | 小程序后台 → 设置 → 基本信息 → 主体信息 → 小程序主体变更 |
| 方向 | **个人 → 企业/个体工商户/组织机构，单向**。目标主体不能是个人 |
| AppID | **不变** ✓ 用户 openid 也不变 |
| 耗时 | 审核约 7 个工作日，通过后 7 天内要确认 |
| 费用 | 有付费环节（以后台显示为准） |
| 材料 | 营业执照；个人账号不支持开增值税专票，只能电子发票 |

变更后原主体就交出去了，**确认无误再提交**。

### ② 微信认证

| 项 | 说明 |
|---|---|
| 前置 | ① 主体变更完成 |
| 费用 | **300 元/年** |
| 时限 | 缴费通知发出后 **24 小时内**必须付款，过期要重建任务 |

### ③ 备案

**前置条件（三项都要先满足）**：

- [ ] 小程序名称、图标、描述等基本信息填写完整
- [ ] **至少一个服务类目已审核通过**
- [ ] 管理员人脸核身

**流程与耗时**：

```
平台初审 1~2 工作日 → 提交管局 → 工信部短信核验 → 管局审核 1~20 工作日
                                    ↑ 收到短信后 24 小时内必须完成，否则自动退回
```

**服务内容说明**（限 20~200 字）已经写好了，直接抄 `config.js` 里的 `filing.note`（当前 128 字）。

## 二、后台配置（🖐 只能你做）

### ① 基本信息

| 项 | 注意 |
|---|---|
| 名称 | 个人主体变更后不能再改主体，名称也可能受限 |
| 图标 | 建议用 `public/assets/favicon.svg` 导出的 PNG |
| 简介 | 写清"为线下门店提供 WiFi 连接工具" |

### ② 服务器域名 / 业务域名 —— **两个都跳过**

后台 → 开发管理 → 开发设置里有两块「开始配置」，**都不用点**。

| 配置项 | 结论 | 依据 |
|---|---|---|
| **服务器域名** | ❌ 不用配 | 本项目**纯前端、零后端**，代码里没有任何 `wx.request` / `uploadFile` / `connectSocket` |
| **业务域名** | ❌ 不用配 | 有 `<web-view>` 页，但 `afterConnect.webviewUrl` 是空的，永远到不了那里 |

怎么确认？跑 `node tools/check-miniprogram.mjs`，它会自动扫代码告诉你：

```
后台「域名配置」需求：
  服务器域名：不用配 —— 代码里没有任何网络请求（纯前端）
  业务域名：不用配 —— 有 web-view 页，但 afterConnect.webviewUrl 是空的
```

**什么时候才需要业务域名**：以后想用 `afterConnect.webviewUrl` 跳领券页 / 公众号文章时。
那时需要：① 一个**已完成 ICP 备案**的域名 ② 把微信校验文件放到该域名根目录 ③ 在后台配为业务域名。

> 现在就算去配也配不上（没有备案域名），直接跳过。

### ③ 服务类目（至少一个通过才能备案）

推荐两个，**资质要求栏都是空的（不需额外许可证）**：

| 类目 | 官方适用范围原文 |
|---|---|
| **工具 → 信息查询** | "适用于提供信息查询功能" |
| **商业服务 → 企业管理** | "…**门店信息管理、展示**等服务" |

一个小程序最多申请 **5 个**，先报这两个。
选类目要**符合营业执照经营范围**——你的执照里有「网络技术服务」，能支撑。

### ④ 用户隐私保护指引 ⚠️ 最容易漏，配错直接废掉功能

**路径**：小程序后台 → 设置 → 功能设置 → 用户隐私保护指引（或 服务内容声明）

微信会根据代码实际调用**自动列出必填项**，但这个项目里有 **两项必须确认已声明**：

| 处理的信息 | 为什么 | 官方原文 |
|---|---|---|
| **收集你的位置信息** | 安卓连 WiFi 要先拿 `scope.userLocation` | 对应接口：`wx.authorize({scope:'scope.userLocation'})` |
| **读取你的剪切板** | 复制密码用了 `wx.setClipboardData` | 对应接口：`wx.setClipboardData`、`wx.getClipboardData` |

**WiFi 接口本身（`startWifi`/`connectWifi`/`getConnectedWifi`）不在隐私接口清单里**，不需要单独声明。

**不声明会怎样**（官方原文）：

```
errMsg: "A:fail api scope is not declared in the privacy agreement"  errno: 112
errMsg: "A:fail appid privacy api banned"   ← 接口被平台回收
```

**两个坑**：

1. 补充声明**5 分钟后才生效**，别刚改完就测
2. 提审时会问"是否采集隐私"——**不能勾"未采集"**，否则接口权限被回收

还需要填：开发者联系方式、信息存储期限、使用规则。

### ⑤ 流量主（变现，可后置）

| 项 | 说明 |
|---|---|
| 门槛 | 页面文档写 **UV ≥ 500**；接口错误码 `2013` 写 **1000**。以你后台实际显示为准 |
| 生效 | 达标后**次日**刷新资格 |
| 操作 | 公众平台 → 流量主 → 开通 → **广告位管理 → 新建激励视频广告位** → 拿到 `adUnitId` |

拿到后 🤖 我帮你填进 `config.js`。

### ⑥ 小程序码（每家门店一张）

**支持两种入码方式，可以混用。**

#### 方式 A：内联（推荐）—— scene 里直接带 WiFi 名和密码

```bash
node tools/gen-mpcode.mjs --appid wx... --secret ...
```

脚本读 `config.js` 的 `stores`，每家店生成一张，scene 形如：

```
ChinaNet-3v9I-5G~88888888      （25 字符）
```

| | |
|---|---|
| ✅ | 门店改密码只需重新生成码，**不用改代码、不用发版** |
| ✅ | 不需要服务器、不需要云开发 |
| ❌ | **scene 上限 32 个可见字符**，SSID+密码 总长必须 ≤ 31 |
| ❌ | **不支持中文**（中文 SSID 用不了） |

脚本会逐个校验并告诉你哪家放不下，输出像这样：

```
✓ 本店           ChinaNet-3v9I-5G~88888888          25 字符
✓ 悦荟城店         YueHuiCheng-5G~yh123456            23 字符
✗ 中文SSID       咖啡厅WiFi~abc12345                   含微信不允许的字符：咖 啡 厅
✗ 超长的          MyShop-VeryLongSSID-5G~mypassword2026 长 37 字符，超出 32
```

#### 方式 B：门店 id —— scene 只带短 id

scene 填 `shop2`，WiFi 信息写在 `config.js` 里。

| | |
|---|---|
| ✅ | 中文店名随便写，WiFi 信息多长都行 |
| ❌ | **改密码必须重新发版**（审核 1~7 工作日 + 用户更新延迟） |

#### 两种怎么选

**先用内联**，放不下的（中文 SSID / SSID 太长）再用 id。两者靠 `~` 区分，
不需要改代码就能同时用。

#### 两个注意

- ⚠️ **小程序码只能你生成**（需要小程序主体的 access_token），门店自己生成不了 →
  所以这个脚本是你（服务商）替门店出码用的
- ⚠️ 参数名就是 **`scene`**（不是 `id`），代码里两个都支持
- 脚本会同时输出一个 `print.html`，浏览器打开后 ⌘P 可直接打印所有码

> 如果是手工在公众平台生成：工具 → 生成小程序码 → 页面选 `pages/ad/index`
> → 参数填 `SSID~密码`（内联）或门店 id

## 常见驳回原因（提前避开）

| 原因 | 怎么避 |
|---|---|
| 服务内容不明确 | 已内置「服务说明」页，明说自己是干什么的 |
| 类目与经营范围不符 | 执照里有「网络技术服务」，选工具/商业服务类目 |
| 未配置隐私保护指引 | 见上面 ③④ |
| 测试号提交 | 确认用的是真实 AppID |
| 服务类目与页面内容不符 | 页面上不要出现类目范围外的内容 |
