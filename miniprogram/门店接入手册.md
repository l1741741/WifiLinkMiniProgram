# 门店接入手册（傻瓜版）

给门店出小程序码的完整流程。**全程只需要 3 条命令**，不用编辑任何文件。

- 面向对象：你本人，或帮你跑门店的同事
- 每接一家新店：约 1 分钟
- 前置知识：无

---

## 一次性准备（只做一次，约 10 分钟）

### 1. 装 Node.js

打开 **https://nodejs.org** → 下载 **LTS** 版 → 双击安装 → 一路「下一步」。

验证装好了：打开「终端」（Windows 是「命令提示符」），输入：

```bash
node -v
```

看到 `v20.x.x` 或更高版本就可以了。

### 2. 拿到这个项目

如果还没下载过，在终端里：

```bash
git clone https://github.com/l1741741/WifiLinkMiniProgram.git
cd WifiLinkMiniProgram
```

> 已经下载过的跳过这步，直接 `cd` 进项目目录。

### 3. 准备两个东西

| 叫什么 | 从哪拿 | 长什么样 |
|---|---|---|
| **AppID** | 微信公众平台 → 开发管理 → 开发设置 | `wx9cc6c1c2ad762236` |
| **AppSecret** | 同上，点「重置」生成 | `a1b2c3d4e5f6...`（32 位） |

> ⚠️ **AppSecret 是密码，别发到群里、别截图给别人。**
> 第一次用的时候会让你输入一次，之后存在本机 `.secrets.json`，
> 不会再进仓库（已加 `.gitignore`）。

**准备完毕。以后每次接店只需要下面 3 步。**

---

## 每接一家新店：3 步

### 第 1 步：加店

在终端里（确保当前目录是项目目录）：

```bash
node tools/add-store.mjs
```

然后它会问你 3 个问题，照着填：

```
  加一家门店
  回车用括号里的默认值；Ctrl+C 退出

  店名（会印在二维码海报上）: 悦荟城店
  WiFi 名称（手机设置里看到的那个，区分大小写）: YueHuiCheng-5G
  WiFi 密码: yh123456
```

**怎么填：**

| 问题 | 怎么答 | 注意 |
|---|---|---|
| **店名** | 随便起，只是给你自己认的 | 会印在海报上，用门店真名最好 |
| **WiFi 名称** | 手机 WiFi 设置里看到的**一模一样**的名字 | ⚠️ **区分大小写**，多个空格都可能连不上 |
| **WiFi 密码** | 门店的 WiFi 密码 | 区分大小写 |

> 💡 **不确定 WiFi 名怎么拼？** 用手机连上那个 WiFi，在「设置 → 无线局域网 / WLAN」里的名字就是标准答案。**照抄，不要自己打。**

第一次跑还会额外问两个：

```
  要生成小程序码，需要 AppID 和 AppSecret
  AppID: wx9cc6c1c2ad762236
  AppSecret: （粘贴，屏幕不会隐藏，注意周围）
```

填完会保存，**以后不再问**。

### 第 2 步：看结果

脚本会打印：

```
  ✓ WiFi 信息能放进小程序码  (明文，23/32 字符)

  ✓ 已写入 config.js
  ✓ 凭证已保存到 .secrets.json（下次不用再输）

  正在生成小程序码...

  ✓ 这家店搞定了

  店名      悦荟城店
  WiFi      YueHuiCheng-5G
  密码      yh123456
  二维码    dist/mpcode/悦荟城店.png
  全部海报  dist/mpcode/print.html

  接下来：
    1. 把 PNG 发给门店，或打印海报贴在收银台
    2. 顾客用微信「扫一扫」→ 直接打开小程序 → 点连接
```

**看到「✓ 这家店搞定了」就是成功了。**

### 第 3 步：给门店

你手上有两个文件，都在 `dist/mpcode/` 文件夹里：

| 文件 | 怎么用 |
|---|---|
| `悦荟城店.png` | **单个门店的二维码**。直接微信发给店长，让他打印 |
| `print.html` | **所有门店的打印页**。双击用浏览器打开，按 `⌘P` / `Ctrl+P` 打印成 A4 海报 |

**发给店长的话可以直接复制这段：**

> 这是你们的 WiFi 二维码。打印出来贴在收银台或门口，顾客用微信扫一扫就能连你们店的 WiFi，不用再问密码了。
> 如果 WiFi 密码改了，告诉我，我给你换一张。

## 其他常用操作

### 看已经加了哪些店

```bash
node tools/add-store.mjs --list
```

```
  id          店名            WiFi 名                scene               长度
  ----------------------------------------------------------------------------
  main        本店            ChinaNet-3v9I-5G      ChinaNet-3v9I-5G~8  25 明文
  shop9       悦荟城店         YueHuiCheng-5G        YueHuiCheng-5G~yh   23 明文
```

### 门店改了密码

**只需要重新生成二维码，不用改代码、不用等审核。**

最简单的做法：先删掉再重加。

```bash
node tools/add-store.mjs --delete shop9 --yes
node tools/add-store.mjs
```

新二维码会覆盖旧的 PNG。**把新的发给门店，让他把旧的换掉。**

> 这就是这套方案最大的好处：**改密码是分钟级的事，不用发版。**

### 一次重新生成所有门店的码

```bash
node tools/gen-mpcode.mjs
```

### 门店关门了

```bash
node tools/add-store.mjs --delete shop9 --yes
```

配置里删掉，二维码不再使用。**已经贴出去的旧码不用管**——顾客扫了会落到默认门店（不会白屏，也不会报错）。

## 遇到问题怎么办

### ❌ 提示「WiFi 信息太长，小程序码装不下」

```
  ✗ WiFi 信息太长，小程序码装不下
    30 字节原始数据，编码后 40 字符（上限 32）
```

**原因**：微信的小程序码最多只能带 32 个字符，WiFi 名 + 密码太长了。
中文一个字占 3 个字符，尤其占地方。

**怎么办（按推荐顺序）**：

1. **把门店 WiFi 名改短**（最快）
   `星巴克免费WiFi` → 改成 `Starbucks-5G`。改一次 WiFi 名，之后就再也不会遇到这问题。

2. **密码改短**：8 位纯数字比 12 位混合字符省地方。

3. **告诉我**，我帮这家店换成「门店 id 模式」
   —— 能放得下任意长度的 WiFi 信息，代价是以后改密码要重新发版。

**判断标准**：中文名 **4 个字以内**基本都没问题，超过就容易超。

### ❌ 提示「AppSecret 不对」或「IP 不在白名单」

```
  ✗ 拿 access_token 失败：40125 invalid appsecret
     提示：AppSecret 不对 —— 公众平台 → 开发管理 → 开发设置，重新复制一次
```

**40125**：AppSecret 复制错了，或者被重置过。去公众平台重新复制。

**40164**：本机公网 IP 不在白名单。去公众平台 → 开发设置 → IP 白名单，把提示里说的 IP 加进去。

### ❌ 提示「page 不存在」

小程序还没发布的时候会出现。加一个参数：

```bash
node tools/add-store.mjs --env develop
```

### ❌ 顾客扫码后没反应 / 打开了网页

**八成是扫码的人不是管理员。** 小程序**发布前**，只有管理员/开发者/体验者扫码才有反应，普通顾客扫了没反应是正常的。

**发布之后**所有人扫都正常。所以：

| 阶段 | 谁扫有用 |
|---|---|
| 发布前（开发阶段） | 只有你自己（管理员） |
| 发布后 | 所有人 |

### ❌ 顾客说「连上了但上不了网」

这是**安卓系统的限制**，不是二维码的问题：

> 安卓 10 以上，小程序自己连的 WiFi 只有小程序能上网，其他 App 用不了。

所以小程序在安卓上会**引导顾客去系统设置里连**（这是正确行为）。iPhone 上则是一键直连。

**顾客问起就这么回答**：安卓上麻烦一点，点一下「复制密码并打开设置」，按页面提示走就行。

## 门店常见提问（照着回答）

**Q：顾客扫不出来怎么办？**
> 让他用**微信扫一扫**（不是用相机），并且环境别太暗。实在不行让他手动连 WiFi，密码是 xxx。

**Q：二维码会不会过期？**
> 不会过期，一直有效。

**Q：能统计有多少人扫码吗？**
> 现在不能。要统计需要额外开发。

**Q：我们改 WiFi 密码了怎么办？**
> 告诉我，5 分钟给你换新码，不用重新走流程。

**Q：能放在公众号/朋友圈推吗？**
> 能，二维码图片直接发就行。

## 给技术同事的备注

上面所有命令都不需要手改文件。原理：

- `add-store.mjs` 会把门店插到 `miniprogram/config.js` 里 `// ===STORE-INSERT===` 标记之前
- 二维码里存的是 `scene = <WiFi名>~<密码>`（纯 ASCII），中文则自动转 base64url
- 小程序端 `app.js` 的 `resolveStore()` 解析这个 scene，**不需要发版**

**这行标记别删**，工具靠它定位插入点：

```js
// ===STORE-INSERT===
```
